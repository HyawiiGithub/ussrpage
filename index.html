2 · pages

Each page is its own address, like #/Leaders. Pick one to open it, or make a new one. Linking a word to a page that doesn't exist yet is fine — opening it later creates it.

3 · write

Write in the big box using the little codes below (or press how to write for the full list with examples). Press save and it appears on the white page instantly, and is remembered in this browser.

4 · design — background, banner, colours, motion

This changes how every page looks. Everything saves by itself as you change it. Easiest start: pick a ready look, then tweak it.

Background. The colour behind everything. Tap the box or paste any colour code (search "colour picker" to find codes). A picture link is optional — leave it empty for plain colour.

Words. Text colour, link colour, heading colour, letter style, letter size, and how wide the page is.

Banner. A big title bar on top of every page. Tick the box, write a title and a smaller line under it, pick its colours. It is the fastest way to make the place feel like yours.

Motion. Pages can fade in softly when opened. (Glowing, wavy, flickering and scrolling words from "how to write" always work.)

Extra code (optional). Only if you know website code — it runs last and beats everything else.

5 · keep it safe

Download backup saves everything to a file. Upload backup puts it back (or moves it to another computer). Wipe deletes every page and returns to a blank.
